# GCP Design System — Component Explorer

Full dashboard (`index.html`) with live previews + real annotated source
for all 12 components built so far, plus the interactive AAM.106 page
example (`algorithm-mapping.html`). Source components are in `components/`,
tokens in `tokens.css`.

## Deploy
Push this repo to GitHub, then connect it as a Vercel project (or ask
Claude to run `create_git_project` once it's pushed) — every future push
auto-deploys, no manual steps needed.
